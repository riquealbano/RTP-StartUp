# RTP - Realidade Tributária dos Proprietários

## 📌 Sobre o Projeto

O **RTP (Realidade Tributária dos Proprietários)** é uma aplicação web desenvolvida como projeto acadêmico e de startup na FACENS, com o objetivo de apresentar e facilitar a compreensão de informações relacionadas à tributação e à realidade financeira de proprietários e trabalhadores.

A plataforma foi desenvolvida buscando transformar informações complexas em dados mais acessíveis, permitindo que o usuário tenha uma visão mais clara sobre sua situação e seus possíveis impactos financeiros.

## 🔐 Autenticação e Segurança

O projeto conta com funcionalidades de cadastro e autenticação de usuários, incluindo validações dos dados enviados pela aplicação.

Durante o desenvolvimento também foram estudadas estratégias de segurança envolvendo:

- Autenticação baseada em tokens (JWT)
- Criptografia de informações
- Validação de dados
- Comunicação com APIs

---

## 📊 Dados e Visualização

O projeto também contempla a utilização de ferramentas de análise e visualização de dados, como **Power BI** e **Metabase**, permitindo transformar os dados coletados em informações mais fáceis de interpretar.
